# 随包演示资料

本目录里的两套软件和全部资料均为虚构，仅用于验证离线问答、格式解析、项目隔离和出处查看，不对应任何公司设备或实际工艺参数。

选择“温度采集与监控软件”后，可试问：

- 设备已经连接成功，为什么没有温度曲线？
- 看到实时曲线，为什么查不到历史数据？
- E203 是什么意思，怎么处理？
- 报警后加热设备会自动停机吗？

该项目包含 PDF 操作手册、Word 常见问题、Excel 通道表和 Markdown 操作注意事项。软件启动后会从资料文件夹读取并建立索引；资料更新后自动重新校对。

选择“设备点检记录工具”后，可问“点检记录怎么提交？”，验证两个项目的资料互不混用。问未定义的故障码时，预期提示缺少资料依据。
