# 离线私库 · 有据问答 v0.1.1

用自己的资料，问有出处的答案。本版采用虚构的温度采集与监控软件、设备点检记录工具演示资料，采用 MIT 许可证。

## 下载与启动

- 普通 Windows x64 用户下载 `offline-private-knowledge-v0.1.1-win-x64.zip`，完整解压后运行 `PrivateKnowledge.Desktop.exe`。客户端和问答服务均自带 .NET 运行时，不需要另装 SDK。
- 源码下载 `offline-private-knowledge-v0.1.1-source.zip`，也可直接克隆仓库。
- `SHA256SUMS.txt` 可核对附件完整性，`release-info.json` 记录版本与运行时信息。

按客户端内首次配置准备 Ollama、回答模型和检索模型，再选择自己的资料目录或随包虚构示例。**附件不包含 Ollama、模型权重、个人或公司知识文件。** 安装和下载模型需要联网；本地资料和模型准备好后，日常索引及问答可离线运行。

## 本版功能

- TXT、Markdown、DOCX、文字型 PDF 和 XLSX 本地解析，按项目文件夹自动更新索引。
- 关键词与语义混合检索、本地模型回答、引用和原文查看。
- 本机自动准备服务，关窗只停止自己启动的服务；企业客户端连接 IT 提供的服务。
- 首次配置、已安装回答模型选择，以及从官方目录浏览和下载模型。
- 自动测试与公开文件检查通过后，才生成和发布源码及运行包。

## 已知边界

这是可运行原型，不能保证模型每句话都忠实于资料；重要答案应核对原文。没有扫描 PDF 的 OCR，没有个人账号或项目级企业权限。Windows 为当前验证平台，尚未完成全新 Windows 虚拟机验收和其他操作系统发布验收。框架支持期限、格式限制、资源需求和部署说明见仓库文档。

依赖库、Ollama 和模型各自遵循上游许可证。项目使用 AI 工具协助实现，模拟测试和真实模型验证分别记录，不将测试通过等同于生产准确率保证。
