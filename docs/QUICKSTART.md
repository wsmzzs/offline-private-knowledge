# 快速开始

## 准备

本轮发布为 Windows x64。Ollama 官方 Windows 要求 Windows 10 22H2 或更新版本；显卡驱动要求以 [官方说明](https://docs.ollama.com/windows) 为准。

小规模资料建议先在约 16 GB 内存电脑试用。这是体验建议，不是官方最低要求或速度保证。CPU 可运行，首次整理较长资料可能需几分钟；模型、上下文和同时运行的软件都会影响资源占用。建议预留至少约 10 GB 可用磁盘，较大模型需要更多。

Windows 运行包已带 .NET 运行时，不要求 Visual Studio 或 SDK。Ollama 和模型需要单独准备。已准备模型的电脑可断网使用；企业方式需要连接内网服务器。

## 本机首次使用

1. 完整解压运行包。不要只复制客户端 EXE，也不要在压缩包里直接运行。
2. 打开 `PrivateKnowledge.Desktop.exe`，选择“在这台电脑使用”。
3. 检查环境。缺少 Ollama 时点击安装页面入口，自行完成官方安装，再回到软件重新检查。
4. 回答模型用于整理答案，检索模型用于找资料。分别点击缺少项的下载按钮；有其他本地回答模型时可以直接选择。
5. 选择资料根目录，或体验随包虚构示例。
6. 进入主界面，等所选知识库就绪后提问。

下载安装只在你明确点击后发生。软件不会自动购买服务或使用云端模型。模型保存位置由 Ollama 管理，与知识资料目录分开。

若希望把模型放到其他磁盘，在首次下载前按 [Ollama Windows 说明](https://docs.ollama.com/windows#changing-model-location) 设置 `OLLAMA_MODELS` 并重新启动 Ollama。客户端不会静默修改系统环境变量。

## 放置自己的资料

```text
我的资料根目录/
  项目甲/
    操作手册.md
    常见问题.docx
  项目乙/
    岗位说明.pdf
    字段说明.xlsx
```

每个一级子文件夹是一套知识库。选择一个知识库只查询这一套资料。根目录说明文件不参与索引。

支持 UTF-8 TXT/MD、DOCX、文字型 PDF 和常规 XLSX。不支持扫描图片 OCR、旧 DOC/XLS 或复杂合并 Excel 表格。保留清晰的标题、字段名和条件，避免混放不同项目、相互冲突的旧版规则。

添加、替换或删除文件后服务自动核对，界面显示进度和新修订号。资料更新不会重写之前的回答，需要重新提问。首次生成向量比重启核对慢，文件未变化时会复用索引。

## 正常关闭

本机方式只停止当前客户端自己创建的问答 API。独立启动的 API、企业服务和 Ollama 均保持独立运行。模型已经下载的文件不会因为关闭客户端被删除。

## 常见情况

- **模型尚未安装：**在首次配置中准备；其他人管理的企业模型请联系 IT。
- **资料目录没有项目：**在根目录下新建一个子文件夹，并放入支持的文件。
- **资料明明有却没有回答：**核对实际目录、文件状态和修订号，再检查引用；检索和回答模型都可能出错。
- **提示目录与已有服务不同：**不要关闭其他人使用的服务；沿用它的目录，或由启动它的人安排切换。
- **第一次整理慢：**保持窗口打开，观察具体文件和片段进度，完成后日常启动可复用。
- **企业重开要求密钥：**密钥不写入普通设置文件，需再次提供，或由 IT 配置专用环境变量。
